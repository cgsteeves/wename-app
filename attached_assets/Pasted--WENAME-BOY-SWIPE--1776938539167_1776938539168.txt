WENAME — BOY SWIPE CARD: VISUAL DESIGN SPECIFICATION
A complete prompt for recreating the boy card's layered appearance exactly
================================================================================

You are building a single React Native (or React web) component that renders
the visual design of the "boy" swipe card from the WeName baby name app.
This document gives you every layer, every color value, every spacing number,
every font setting, and every asset filename needed to produce a pixel-exact
replica.

Do not guess or approximate any value — every measurement is sourced directly
from the production code.

================================================================================
SECTION 1 — CARD OUTER SHELL
================================================================================

The card is a rounded rectangle that fills its parent container.
It clips all child layers (overflow: hidden).

Shape:
  borderRadius:  16  (Tailwind: rounded-2xl)
  width:         100% of parent
  height:        100% of parent
  overflow:      hidden

Borders and shadows:
  border:        2px solid  hsl(35, 22%, 80%) at 40% opacity
                 Tailwind class: border-2 border-border/40
                 Computed border color: rgba(192, 183, 170, 0.40) approx
  boxShadow:     shadow-2xl
                 Web: 0 25px 50px -12px rgba(0,0,0,0.25)
                 RN:  elevation: 24, shadowColor: '#000',
                      shadowOpacity: 0.25, shadowRadius: 25,
                      shadowOffset: { width: 0, height: 12 }

Fallback background (visible for ~100ms before the image loads):
  backgroundColor: hsl(38, 45%, 93%)   — the app's "parchment" color
                   Hex approx: #EDE0C8

All child elements are absolutely positioned inside this shell.

================================================================================
SECTION 3 — VIGNETTE OVERLAY (LAYER 2)
================================================================================

A dark edge vignette sits directly on top of the photo.
This darkens the card corners/edges slightly to improve legibility of
any text or UI that appears near the edges.

Position: absolute, inset: 0
pointer-events: none
z-index:  above background image

CSS:
  background: radial-gradient(
    ellipse at center,
    transparent 0%,
    transparent 60%,
    rgba(0, 0, 0, 0.15) 100%
  );

This means:
  - Center 60% of the card: fully transparent (photo shows through cleanly)
  - From 60% to edges: darkens gradually to 15% black at the very corners
  - The gradient is elliptical and centered

--- PASS BUTTON (left) ---
  Size: 64x64  (w-16 h-16)
  borderRadius: 32  (rounded-full)
  border: 2px solid rgba(255,255,255,0.60)

  Background gradient:
    linear-gradient(145deg, hsl(38,50%,96%) 0%, hsl(38,45%,92%) 100%)
    This is a warm off-white gradient. At 0% stop: hsl(38,50%,96%) ≈ #F7F0E3
    At 100% stop: hsl(38,45%,92%) ≈ #EEE0CA
    The 145deg angle creates a top-left highlight to bottom-right shadow.

  Box shadow (ALL THREE applied together on web):
    0 6px 20px rgba(0,0,0,0.25)            — main drop shadow, vertical lift
    0 2px 6px rgba(0,0,0,0.15)             — close ambient shadow
    inset 0 1px 2px rgba(255,255,255,0.80) — top inner edge highlight

  RN equivalent:
    elevation: 8
    shadowColor: '#000'
    shadowOpacity: 0.25
    shadowRadius: 10
    shadowOffset: { width: 0, height: 6 }
    (inner highlight not possible in RN — omit or approximate with border)

    filter:     drop-shadow(0 1px 2px rgba(0,0,0,0.20))
    In RN: wrap in a View with subtle shadow instead of filter

  On press: scale to 0.90  (active:scale-90)

"LIKE" text element (absolutely positioned ON TOP of the image):
  Position: absolute, top: 28, right: 28  (top-7 right-7)

  Color:  white
  textShadow: 0 1px 4px rgba(0,0,0,0.35)
  transform: rotate(22deg)   — tilted clockwise
  The text is centered within its absolute positioned container.

Animation (driven by card's horizontal drag position x):
  opacity:
    x=0:               0      (fully invisible at rest)
    x=THRESHOLD*0.5:   0.7    (50% to threshold = 70% visible)
    x=THRESHOLD:       1.0    (at threshold = fully visible)
  scale:
    x=0:               0.7    (small at rest)
    x=THRESHOLD:       1.15   (slightly overshoots at threshold)
  (THRESHOLD = screen_width * 0.27, e.g. 105px on a 390px screen)

    z=20 : Center section (name, last name, pronunciation, partner badge)
    z=20 : Bottom action row (pass button, undo button, like button)

SECTION 9 — FONT SETUP
================================================================================

Two fonts are used in the entire boy card:

  FREDOKA ("display" font):
    Source:  Google Fonts — "Fredoka" family
    Weights: 400 (Regular), 500 (Medium), 600 (SemiBold), 700 (Bold)
    Used for: remaining count text, "More info" button text, main name (700),

    Source:  Google Fonts — "Patrick Hand" family
    Weights: 400 only (single weight)
    Used for: "Boy Name" label text (italic)
    CSS variable: --font-hand: 'Patrick Hand', cursive
    Tailwind utility: .font-hand { font-family: var(--font-hand) }

Web import (CSS):
  @import url('https://fonts.googleapis.com/css2?family=Fredoka:wght@400;500;600;700&family=Patrick+Hand&display=swap');

React Native import:
  @expo-google-fonts/fredoka
  @expo-google-fonts/patrick-hand
  Use useFonts() hook from expo-font, show splash until loaded.
