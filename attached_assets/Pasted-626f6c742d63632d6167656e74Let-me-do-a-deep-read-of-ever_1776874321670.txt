SECTION 23 — ANIMATION REFERENCE
================================================================================

All Framer Motion animations translate to react-native-reanimated as follows:

Framer: initial opacity 0, y 24, animate opacity 1, y 0, duration 0.7
RN:     useSharedValue(0) + withTiming, entering: FadeInDown.duration(700)

Framer: spring stiffness 350, damping 35 (used on ALL bottom sheets)
RN:     withSpring(0, { stiffness: 350, damping: 35 })

Framer: AnimatePresence (fade + scale on mount/unmount)
RN:     Animated.Modal or conditional render with FadeIn/FadeOut from reanimated

Onboarding page transitions:
  Framer: horizontal slide, x: ±40, opacity 0→1, duration 0.35 ease-in-out
  RN:     SlideInRight / SlideOutLeft from reanimated layouts

Swipe card rotation + opacity interpolation:
  RN: useAnimatedStyle + interpolate(dragX, inputRange, outputRange)

Swipe fly-off:
  RN: withTiming(exitX, { duration: ms, easing: Easing.bezier(0.25,0.46,0.45,0.94) })

Toast notification:
  RN: FadeInDown.duration(300) entering, FadeOutUp exiting

Scale-in match modal:
  RN: ZoomIn.springify() or custom: withSpring(1, { stiffness: 300, damping: 18 })
  Starting scale: 0.8, starting opacity: 0

Bounce (heart icon in match modal):
  RN: withRepeat(withSequence(withTiming(-8), withTiming(0)), -1, true)
  or use Animated.loop with spring

Step dots (active dot width 24→8 transition):
